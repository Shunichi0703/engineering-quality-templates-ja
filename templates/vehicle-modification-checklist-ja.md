## 1. 要求と変更管理

- [ ] 改造目的と完了条件が測定可能である
- [ ] 変更前後の構成差分が説明できる
- [ ] 影響を受ける機能、文書、点検項目を洗い出している
- [ ] 適用する安全要求とその他要求を確認している
- [ ] 承認する役割と作業する役割を分けている

## 2. 構造・強度・締結

- [ ] 追加質量、重心、荷重経路への影響を確認している
- [ ] 静荷重、疲労、振動、衝撃への強度を確認している
- [ ] 穴あけ、切断、溶接による母材への影響を評価している
- [ ] 締結部の強度、緩み止め、締付条件に根拠がある
- [ ] 鋭利部、突起、脱落物が生じない構造である

## 3. 配置・干渉・環境

- [ ] 可動部、操舵部、懸架部との全可動域で干渉しない
- [ ] 地上高、視界、乗降、整備アクセスへの影響を確認している
- [ ] 熱源、排気、可燃物との距離と遮熱を確認している
- [ ] 水、粉じん、腐食、振動への保護を確認している

## 4. 電気・流体

- [ ] 電源容量、保護装置、配線経路、接地を確認している
- [ ] 電磁的な影響と故障時の挙動を確認している
- [ ] 配管の圧力、温度、曲げ、摩耗、漏れ対策を確認している
- [ ] 切離し、停止、エネルギー遮断の方法が明確である

## 5. 走行・操作・安全

- [ ] 制動、操舵、安定性、タイヤ負荷への影響を確認している
- [ ] 運転者の操作、表示、警告が分かりやすい
- [ ] 通常時、故障時、緊急時の安全な状態を確認している
- [ ] 点検者や整備者の作業安全を確認している

## 6. 作業と検証

- [ ] 作業手順、工具、品質確認点が定義されている
- [ ] 作業前後の検査項目と合否基準がある
- [ ] 停止状態、低負荷、通常条件の順に機能確認する
- [ ] 改造後の走行または機能試験に安全な中止条件がある
- [ ] 写真や記録から公開禁止情報を除去している

## 7. 復旧と運用

- [ ] 問題発生時の使用停止条件が明確である

- [ ] 関係する取扱・整備文書を更新している
