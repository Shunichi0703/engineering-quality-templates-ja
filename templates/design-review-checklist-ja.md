## 1. 要求と境界条件

- [ ] 機能要求と性能要求が測定可能である
- [ ] 使用環境、寿命、保管、輸送条件が定義されている
- [ ] 接続先との機械、電気、流体、情報の境界が明確である
- [ ] 通常、誤使用、保守、故障時の状態を考慮している
- [ ] 要求間の矛盾と優先順位を確認している

## 2. 荷重と強度

- [ ] 静荷重、動荷重、衝撃、振動、熱荷重を洗い出している
- [ ] 荷重経路、拘束条件、組合せ条件が妥当である
- [ ] 強度、剛性、疲労、座屈の評価方法と判定基準がある
- [ ] 解析条件と実機条件の差を把握している
- [ ] 安全率の根拠と適用範囲が明確である

## 3. 材料と表面

- [ ] 材料特性が荷重、温度、環境、寿命に適合している
- [ ] 腐食、摩耗、劣化、異種材接触を考慮している
- [ ] 表面処理と後工程への影響を確認している
- [ ] 材料や処理の代替時に再確認すべき条件が明確である

## 4. 寸法と公差

- [ ] 基準、機能寸法、測定方法が一致している
- [ ] 公差積上げで最悪条件を確認している
- [ ] はめあい、隙間、干渉、熱変位を確認している
- [ ] 製造能力および検査能力と公差が整合している

## 5. 製造・組立・保守

- [ ] 加工、成形、接合、締結が安定して実施できる
- [ ] 組付方向、工具空間、誤組付け防止を考慮している
- [ ] 締結条件と緩み防止方法に根拠がある
- [ ] 検査、交換、清掃、調整へ安全にアクセスできる
- [ ] 廃棄または分解時の注意事項が明確である

## 6. リスクと適用要求

- [ ] 故障モードと影響を確認し、高リスク項目へ対策している
- [ ] 単一故障、共通原因、連鎖的な影響を確認している
- [ ] 適用する安全要求、社内基準、その他要求を特定している
- [ ] 保護機能の故障検出と安全側動作を確認している

## 7. 検証と妥当性確認

- [ ] 各要求に解析、試験、検査、レビューのいずれかが対応する
- [ ] 試験条件が実使用の厳しい条件を代表している
- [ ] 合否基準、測定精度、試験前後の状態確認が明確である
- [ ] 設計変更後に再実施する確認範囲が定義されている
