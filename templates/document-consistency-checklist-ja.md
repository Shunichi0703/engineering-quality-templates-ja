# 技術文書整合性チェックリスト

## 対象

- 文書の目的: [設計、製造、検査、運用など]
- 対象文書: [公開可能な汎用名称]
- 比較対象: [関連仕様、試験記録、手順など]
- レビュー範囲: [章、変更箇所、文書一式など]

## 1. 基本情報と構成

- [ ] タイトル、目的、対象範囲、対象読者が一致している
- [ ] 版、発行日、状態、変更理由が明確である
- [ ] 目次、見出し、番号、参照先が本文と一致している
- [ ] 廃止情報や未承認情報が現行情報と混在していない

## 2. 用語・記号・単位

- [ ] 同じ対象に同じ名称を使用している
- [ ] 略語、記号、添字を初出時に定義している
- [ ] 単位系、桁数、丸め、許容差の表記が統一されている
- [ ] 「以下」「未満」など境界を含む表現が明確である

## 3. 要求と数値

- [ ] 要求値、目標値、参考値を区別している
- [ ] 表、図、本文、計算の数値が一致している
- [ ] 計算式の入力、前提、結果、単位を追跡できる
- [ ] 変更した数値が関連箇所へ反映されている

## 4. 文書間の整合

- [ ] 仕様、設計、製造、検査、運用の内容が矛盾していない
- [ ] 各要求に検証方法と合否基準が対応している
- [ ] 図表、付録、外部参照の名称と内容が一致している
- [ ] 参照先の版または適用時点が明確である

## 5. 手順と責任

- [ ] 手順の開始条件、順序、終了条件が明確である
- [ ] 通常時、異常時、中止時の処置が記載されている
- [ ] 実施、確認、承認の役割が明確である
- [ ] 記録する結果と保存方法が明確である

## 6. 可読性と公開前確認

- [ ] 読者が必要な判断を文書だけで実行できる
- [ ] 曖昧語に判定基準または具体例がある
- [ ] 画像、代替テキスト、表題が内容と一致している
- [ ] 識別情報、個人情報、機密情報を除去している
- [ ] リンク、添付、コメント、メタデータも確認している
